# Análise Crítica das Adaptações Existentes & Lições Aprendidas

## 1. Fighting Fantasy Classics (Tin Man Games, 2018)

### O Que Copiar
| Mecânica | Justificativa |
|----------|---------------|
| **Adventure Sheet automático** (stats + inventário + conhecimento) | Remove fricção de bookkeeping manual; jogador foca na história |
| **Unlimited Bookmarks** como save system | Melhora massiva sobre o original; permite experimentação sem punição |
| **Mapa de exploração cross-playthrough** | Mostra todos os caminhos já percorridos em jogadas anteriores; incentiva replay |
| **Free Read Mode** (sem desafio) | Permite que qualquer um experiencie a história; acessibilidade cognitiva |
| **Múltiplos níveis de dificuldade** (Classic/Easy/Hardcore) | Respeita puristas e acolhe novatos |
| **Galeria de arte colecionável** | Valoriza o aspecto artístico; metagame de coleção |
| **Fast dice / animação acelerável** | Respeita o tempo do jogador veterano |
| **Estante visual com livros face-out** | Apresentação temática; decisão de compra visual |
| **Steam Cloud save** | Continuidade entre dispositivos |

### O Que Criticar / Melhorar
| Problema | Gravidade | Solução Proposta |
|----------|-----------|-----------------|
| **Mobile-first UI no PC** (texto "touch" em vez de "click") | 🔴 Alta | UI responsiva nativa por plataforma; atalhos de teclado completos |
| **Bookmarks não nomeáveis** (só número do parágrafo) | 🔴 Alta | Bookmarks com nome customizável + preview do texto + timestamp |
| **Sem atalhos de teclado** no PC | 🟠 Média | Teclas 1-4 para escolhas, B=bookmark, M=mapa, Esc=menu |
| **Sem suporte a leitor de tela** | 🔴 Alta | Integração nativa com screen readers (NVDA, VoiceOver, TalkBack) |
| **Sem narração TTS** | 🔴 Alta | Narração automática toggleável por seção |
| **Sem modo escuro/alto contraste** | 🟠 Média | Temas: Claro, Escuro, Sépia, Alto Contraste (preto/amarelo) |
| **Sem seleção de fonte** (só tamanho) | 🟡 Baixa | Serif, Sans-serif, OpenDyslexic, tamanho e espaçamento |
| **Sem histórico de escolhas** | 🟠 Média | Timeline visual com todas as decisões da run atual |
| **Sem dicas** para caminhos críticos | 🟡 Baixa | Sistema opcional de hint (ex: "você sente que esqueceu algo...") |
| **Sem comparação de runs** | 🟡 Baixa | Dashboard de progresso: % explorado, finais descobertos, mortes |
| **Sem Workshop/community content** | 🟠 Média | Importação de histórias da comunidade via JSON |
| **DLCs exigem recompra** (migração de app standalone) | 🔴 Alta | Sistema de conta com biblioteca unificada; compra uma vez, joga em qualquer plataforma |

## 2. Sorcery! (Inkle Studios, 2013-2016)

### O Que Copiar
| Mecânica | Justificativa |
|----------|---------------|
| **Mapa 3D desenhado à mão** com navegação drag | Substitui "vá para página X" por escolha espacial intuitiva |
| **Sistema de Rewind** (voltar no tempo para qualquer decisão) | Permite experimentação sem frustração; diegeticamente integrado |
| **Combate tátil** (swipe/drag para atacar/defender) | Muito mais envolvente que rolagem de dados automática |
| **Narração procedural de combate** (texto único por golpe) | Cada luta gera história, não só números |
| **Persistência cross-game** (decisões do livro 1 afetam livro 4) | Sentido épico de jornada contínua |
| **Storylet engine** (narrativa que se reescreve baseada em estado) | Reatividade narrativa profunda; mesmo texto nunca se repete igual |
| **Diegetic mechanics** (ex: perdeu dedo → afeta gameplay futuro) | Imersão total; consequências importam |
| **Male/Female choice** | Inclusão básica de gênero |
| **Sistema de magia contextual** (48 spells com códigos de 3 letras) | Profundidade estratégica além do combate |

### O Que Criticar / Melhorar
| Problema | Gravidade | Solução Proposta |
|----------|-----------|-----------------|
| **Spellcasting horrível no PC** (interface touch-first) | 🔴 Alta | UI nativa por plataforma; drag no mobile, grid/seleção no PC |
| **Inventário "colossal mess"** no PC | 🔴 Alta | Grid organizável com filtros, busca, e tooltips |
| **Parte 1 muito curta** (sensação de demo paga) | 🟠 Média | Cada história deve ser autocontida com arco satisfatório |
| **Armadilhas "fuck you"** (morte instantânea sem aviso) | 🟡 Baixa | Mortes devem ter foreshadowing; opção de "rewind 1 passo" |
| **Rewind pode ser tedioso** (repetir seções longas) | 🟠 Média | Skip rápido de texto já lido; fast-forward inteligente |
| **Sem acessibilidade** (zero opções) | 🔴 Alta | Todas as opções de acessibilidade listadas acima |
| **Sem exportação de save** | 🟡 Baixa | Cloud save + export/import de arquivo de save |
| **PC Metacritic 69/100 vs iOS 85-90/100** | 🔴 Alta | Desenvolver PC-first ou true-cross-platform, não mobile-first portado |

## 3. 80 Days (Inkle, 2014)

### O Que Copiar
| Mecânica | Justificativa |
|----------|---------------|
| **Mapa-múndi como interface de escolha** (rotas visíveis) | Navegação espacial substitui menu de texto |
| **Recurso triplo** (dinheiro/saúde/tempo) com trade-offs reais | Decisões com peso; impossível otimizar tudo |
| **750K palavras, ~2% vistas por run** | Replayability massiva via volume de conteúdo |
| **Escolhas naturalistas** (integradas ao texto, não botões separados) | Leitura fluida; imersão |
| **Sem "game over" tradicional** (sempre há próximo destino) | Elimina frustração de morte; foco na jornada |
| **Textos concisos** (1-2 parágrafos por seção) | Ritmo rápido; ideal para mobile |
| **Diário de bordo** (log narrativo da jornada) | Reforça sensação de viagem; pode ser exportado/compartilhado |

### O Que Criticar / Melhorar
| Problema | Gravidade | Solução Proposta |
|----------|-----------|-----------------|
| **Auto-save apenas** (sem save manual) | 🟠 Média | Save manual + auto-save com múltiplos slots |
| **Pressão de tempo frustrante** para completionistas | 🟡 Baixa | Modo "relaxed" sem timer; timer como opção |
| **Sem voice acting** (750K palavras seria caro) | 🟡 Baixa | TTS como alternativa gratuita e escalável |
| **Sem acessibilidade** | 🔴 Alta | Full accessibility stack |

## 4. Choice of Games / Hosted Games (2009+)

### O Que Copiar
| Mecânica | Justificativa |
|----------|---------------|
| **Opposed-pair stats** (ex: Ruthless 60% / Merciful 40%) | Sem "max everything"; trade-offs reais de personalidade |
| **Stat-gated choices** visíveis mas travados | Clareza: jogador vê o que perdeu; incentiva replay |
| **ChoiceScript como linguagem acessível** para autores | Barreira zero para escritores; foco em texto |
| **Modelo de publicação 3-tier** (curadoria + comunidade) | Ecossistema sustentável de conteúdo |
| **200+ títulos** no catálogo | Prova de que o modelo escala |
| **Primeiros capítulos grátis** | Experimente antes de comprar |

### O Que Criticar / Melhorar
| Problema | Gravidade | Solução Proposta |
|----------|-----------|-----------------|
| **Gates arbitrários** ("precisa 71% Ruthless, você tem 70%") | 🔴 Alta | Thresholds visíveis ao jogador; opção de "forçar" com custo |
| **UI datada** (texto puro, sem ilustrações) | 🟠 Média | Layout 3 painéis com ilustração + stats; suporte a mídia rica |
| **Zero acessibilidade** | 🔴 Alta | Full stack |
| **Sem narração/áudio** | 🟠 Média | TTS integrado |
| **Sem mapa/visualização espacial** | 🟡 Baixa | Mapa de progresso opcional para autores que quiserem |

## 5. Disco Elysium (ZA/UM, 2019)

### O Que Copiar
| Mecânica | Justificativa |
|----------|---------------|
| **Skills como vozes na cabeça** (24 skills falam com o jogador) | Maior inovação narrativa da década; fragmentação de personalidade |
| **Thought Cabinet** (internalizar pensamentos para bônus/malus) | Sistema de progressão narrativo, não numérico |
| **"Embrace failure"** (falhar revela tanto quanto ter sucesso) | Remove medo de falhar; todos os caminhos são válidos |
| **Sem combate tradicional** | Foco total em narrativa e escolhas |
| **Voice acting toggleável** (narrador/personagens/todos/nenhum) | Modelo de acessibilidade de áudio |
| **Tipografia forte** (fonte grande, legível, bem espaçada) | Exemplo de UI acessível por padrão |
| **Diálogo em painel lateral** com retratos | Layout testado e aprovado |

### O Que Criticar / Melhorar
| Problema | Gravidade | Solução Proposta |
|----------|-----------|-----------------|
| **1.2M palavras** (escopo inviável para indie) | 🔴 Alta | Começar com 20-50K palavras por história; expandir com DLCs |
| **Replayability limitada** (mesma história base) | 🟠 Média | Conteúdo procedural + variações por build de personagem |
| **Pesado/lento** (ritmo contemplativo) | 🟡 Baixa | Opção de ritmo: contemplativo vs rápido |
| **Político-divisivo** (não é problema, mas nichado) | 🟡 Baixa | Suporte a qualquer tom/tema; o editor não impõe conteúdo |

| Problema | Gravidade | Solução Proposta |

| Gap | Solução |

| **Nenhuma tem flow analysis estático** | Nosso FlowAnalyzer: dead ends, órfãos, loops, unreachable, item/flag sem uso |
| **Nenhuma tem preview mobile** | Emulador inline no editor: veja como fica no celular |
| **Nenhuma tem edição de assets inline** | Upload de imagens, sons, config de hápticos direto no editor |
| **Nenhuma é verdadeiramente web-first** | 100% browser; Google Cloud Run + Firestore + Cloud Storage |
| **Nenhuma tem versionamento integrado** | Histórico de versões automático com diff visual no grafo |

## 10. Síntese: Nossos 5 Diferenciais Fundamentais

1. **Acessibilidade Total** — Nenhum gamebook digital existente oferece screen reader, narração TTS, controle por voz, swipe, e alto contraste. Este é nosso principal diferencial de mercado.

2. **Story Editor Web Colaborativo** — Nenhuma ferramenta de IF oferece editor de grafo web-based com colaboração em tempo real, preview inline, upload de assets multimídia, e auditoria automática de fluxo. O editor É o produto — ele cria o ecossistema de conteúdo.

3. **Narração + Hápticos como First-Class Features** — A narração não é um afterthought; cada seção pode ter voz, entonação, e velocidade configuradas. Hápticos são configuráveis por evento (combate, descoberta, perigo). Conteúdo multissensorial.

4. **Flow Analyzer Inteligente** — Auditoria estática que detecta dead ends, nós órfãos, loops infinitos, caminhos inalcançáveis, itens/flags sem uso, gates sem fonte, e inconsistências de balanceamento. Profissionaliza o trabalho do escritor.

5. **Cross-Platform Verdadeiro** — Web + PC + Mobile com UI nativa por plataforma (não mobile portado para PC). Cloud save unificado. Compre uma vez, jogue em qualquer lugar.
